# 늙크크 표현 후보 200개

늙크크 판독기·생성기의 초기 데이터 설계를 위한 창작 시드 데이터다. 기존 관용구, 옛 유행어, 예전 인터넷 말투를 활용해 예문을 구성했다. 실제 커뮤니티에서 늙크크로 합의된 표현 200개를 수집한 자료는 아니다.

- 모든 항목은 **사람의 검토 전 후보**다. 실제 나이나 세대를 판정하는 근거로 사용하지 않는다.
- 일반적인 표현은 의미를 비교하기 위한 예시이며, 문맥에 따라 다른 문장으로 바꿀 수 있다.
- 익숙한 관용구도 포함되어 있다. 표현이 등장했다는 이유만으로 늙크크라고 확정하지 않는다.
- 생성기 참고 자료로 먼저 활용하고, 판독기에 쓰려면 일반 문장·인용 문장·애매한 예시를 추가해 사람이 라벨을 검토한다.
- 같은 시드로 만든 예문은 학습·참고 데이터와 독립적인 평가 데이터로 동시에 사용하지 않는다.
- 기계 처리용 파일: [old-keke-expressions.json](./old-keke-expressions.json)
